# Assets Directory

This folder is intended for static and local image/vector assets.

### Official Assets Checklist:
- **PC Official Logo**: Once approved by leadership, save the transparent PNG/SVG as `pc-logo.png` or `pc-logo.svg` here.
- **AIKTC Crest / Emblem**: Place official institute logos here.
- **Event Posters / Graphics**: High-res graphics for upcoming workshops.

*Note: Please compress images (WebP/SVG preferred) before committing to keep repository clone times fast.*
